# Issue #006：实现 Session 任务发现

## 类型

Feature

## 状态

Draft

## 背景

同一项目下的多个 Session 需要共享任务，而不同项目必须保持隔离。任务发现应由当前工作目录和 Git 根目录决定。

## 用户故事

作为开发者，我希望在项目任意 Session 中打开任务列表，并且只看到当前项目的任务。

## 最小范围

1. Session 启动时读取当前工作目录。
2. 通过项目根目录接口定位当前项目。
3. 读取 `.tinyagent/tasks/` 中的任务。
4. 默认返回未归档任务。
5. 提供显式刷新能力。
6. 无 Git 项目时返回空项目上下文。

## 非目标

- 不跨项目扫描。
- 不自动猜测当前任务。
- 不持久化 Session 与任务的绑定关系。

## 验收标准

- 同一项目的多个 Session 看到同一组任务。
- 不同项目任务不会混入当前列表。
- 刷新后可以看到其他 Session 已提交的任务。
- 无 Git 项目时不会读取父目录任务。

## 技术约束

- Session 只依赖项目发现和任务领域接口。
- 发现逻辑不依赖具体前端或命令行入口。
