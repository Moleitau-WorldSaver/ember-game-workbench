# Issue #005：实现任务状态流转和归档恢复

## 类型

Feature

## 状态

Draft

## 背景

任务需要有清晰的生命周期，归档也需要保留历史而不能直接删除任务文件。

## 用户故事

作为开发者，我希望按明确规则推进任务，在完成后归档，并在需要时恢复任务。

## 最小范围

1. 实现 `todo`、`in_progress`、`blocked`、`done` 和 `archived`。
2. 校验合法状态转换。
3. 归档时保存归档前状态和时间。
4. 恢复时回到归档前状态。
5. 让归档任务默认从普通列表隐藏。

## 非目标

- 不提供物理删除。
- 不增加负责人、标签、优先级和子任务。
- 不自动改变任务状态。

## 验收标准

- 合法状态转换可以执行。
- 非法状态转换会被拒绝。
- 任何活动状态都可以归档。
- 恢复任务后状态回到归档前状态。
- 归档任务仍然可以单独查询。

## 技术约束

- 状态转换规则集中定义。
- 归档和恢复使用与普通修改相同的版本校验。
