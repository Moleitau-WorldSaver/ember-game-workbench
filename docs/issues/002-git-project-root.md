# Issue #002：识别 Git 项目根目录

## 类型

Infrastructure

## 状态

Draft

## 背景

Session 必须先确定所属项目，任务上下文才能保持项目隔离。第一版以最近的 Git 根目录作为项目边界，不扫描总根目录或其他项目。

## 用户故事

作为开发者，我希望从项目任意子目录启动 Session 时，系统都能找到正确的项目根目录，并只加载这个项目的任务。

## 最小范围

1. 从当前工作目录向上查找最近的 `.git` 目录或 `.git` 文件。
2. 支持普通 Git 仓库和 Git worktree。
3. 返回项目根目录或明确的无项目结果。
4. 为后续任务发现提供稳定的项目根目录接口。

## 非目标

- 不读取任务文件。
- 不创建总根目录任务。
- 不自动选择父目录或兄弟目录作为项目。

## 验收标准

- 在项目任意子目录都能找到正确的 Git 根目录。
- 嵌套 Git 项目使用最近的根目录。
- Git worktree 能正确识别其工作树根目录。
- 非 Git 目录不会误用其他项目根目录。

## 技术约束

- 根目录识别接口与任务存储解耦。
- 路径判断需要覆盖 `.git` 目录和 worktree 的 `.git` 文件。
