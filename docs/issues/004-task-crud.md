# Issue #004：实现任务增删改查

## 类型

Feature

## 状态

Draft

## 背景

任务存储建立后，需要提供最小的任务操作能力，供 Session 和后续入口使用。

## 用户故事

作为开发者，我希望创建、查看和修改项目任务，并在普通列表中看到未归档任务。

## 最小范围

1. 创建任务并生成稳定唯一 ID。
2. 列出项目任务并支持按状态过滤。
3. 读取单个任务详情。
4. 修改标题和描述。
5. 默认列表隐藏归档任务。

## 非目标

- 不定义复杂状态流转。
- 不提供物理删除。
- 不实现跨项目查询。

## 验收标准

- 创建后可以通过 ID 读取任务。
- 列表结果只来自当前项目任务目录。
- 标题和描述修改后更新时间正确更新。
- 默认列表不包含 archived 任务。
- 不存在的任务返回明确错误。

## 技术约束

- 基础操作通过领域接口暴露，不绑定具体 UI。
- 列表读取应忽略临时文件和无效文件。
