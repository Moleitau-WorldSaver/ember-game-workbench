# Issue #008：接入实际 Session 入口

## 类型

Integration

## 状态

Draft

## 背景

核心任务模块完成后，需要接入仓库实际的 Session 工作流，让开发者能够在真实使用入口中查看和操作任务。

## 用户故事

作为开发者，我希望 Session 启动后可以查看、刷新和选择任务，而不需要手动定位任务文件。

## 最小范围

1. 确认仓库当前的 Session 入口。
2. 在 Session 启动流程中加载当前项目任务。
3. 提供查看和刷新任务的入口。
4. 提供显式选择任务的入口。
5. 将并发冲突转换为 Session 可理解的结果。

## 非目标

- 不自动分配任务。
- 不增加实时协同界面。
- 不改变现有 Agent 运行协议。

## 验收标准

- 真实 Session 可以查看当前项目任务。
- 刷新后能看到其他 Session 的最新提交。
- 不同项目 Session 不会显示彼此任务。
- 任务冲突有明确提示并允许重新读取。

## 技术约束

- 入口适配层依赖稳定的任务领域接口。
- 不把具体 UI 交互写入任务存储模块。
